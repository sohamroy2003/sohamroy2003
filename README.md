* **🧪 Currently Experimenting With** — e.g. Agentic AI, vector databases, embeddings, fine-tuning, multimodal models.
* **📈 ML Metrics on featured projects** — `F1: 0.92`, `R²: 0.89`, etc. *only when they're real*. This looks much stronger than another technology badge.
* **📚 Research / Learning section** — notebooks, Kaggle work, experiments, or technical write-ups.
* **🏗️ Production AI** — Docker/AWS/API deployment projects. This distinguishes you from profiles containing only Jupyter notebooks.
* **🐍 Contribution snake** — visually cool, but I'd put it at the **very bottom** so it doesn't turn the README into a gimmick.
